# Github Website Clone

A pixel-perfect, fully responsive clone of Porsche homepage built as a front-end practice project using **Tailwind CSS** and pure **HTML/CSS**.

| Technology | Purpose |

| CSS 3 | Custom styling & animations |

## Installation

```bash
# Clone the repository
git clone https://github.com/ali-mirzaei-dev/Porsche-Website.git

# Navigate to project directory
cd Porsche-Website

# Open with Live Server or open index.html in browser
`````
